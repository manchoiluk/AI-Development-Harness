# Workflow

The AI must follow this fixed flow every time it works:

```text
1. READ
2. UNDERSTAND
3. CHECK STATE
4. IDENTIFY TASK
5. CHECK SCOPE
6. PLAN
7. IMPLEMENT
8. TEST
9. VERIFY
10. UPDATE STATE
11. REPORT
```

## READ

Read relevant context.

## UNDERSTAND

Clarify:

- Current objective
- Input
- Output
- Constraints
- Acceptance Criteria

## CHECK STATE

Confirm the current project state.

## IDENTIFY TASK

Confirm the current Task.

When no Task exists:

> Do not create large feature tasks on your own.

## CHECK SCOPE

Confirm the change does not cross boundaries.

## PLAN

Form a short implementation plan first.

## IMPLEMENT

Implement only the current Task.

## TEST

Run relevant tests.

## VERIFY

Check:

- Functionality
- Spec
- Scope
- Product Drift

## UPDATE STATE

Update state.

## REPORT

Report:

```text
Completed
Tests
Verification
Files Changed
Remaining Issues
```
