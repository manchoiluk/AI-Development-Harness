## Core Principles

A Task MUST be able to answer:

- Why? (Source Requirement / Spec / Design)
- What? (Objective)
- Scope? (Scope)
- Not Scope? (Non-Scope)
- How to know it is done? (Acceptance Criteria)
- How to test it? (Tests)
- Where did it come from? (Traceability IDs)

If any of these cannot be answered, the Task is:

```text
NOT READY
```
